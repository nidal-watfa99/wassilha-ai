# نظام التصميم (DESIGN SYSTEM)

## المصدر

رموز التصميم أدناه **مُلاحظة فعلياً** وغير مختلقة، بطريقتين:

1. عرض https://nidal-watfa99.github.io/NIDAL-WATFA/?lang=ar في متصفح حقيقي (سحابي) وأخذ لقطة للواجهة المُصيَّرة.
2. قراءة ملف CSS المُجمَّع للموقع (`assets/index-CiNm10Ss.css`) واستخراج خصائصه المخصصة حرفياً.

يُنفّذ `frontend/src/styles/design-system.css` هذه الرموز بعينها.

## الشكل والحركة والعمق

| الرمز | القيمة |
|------|--------|
| `--radius` | `16px` (بطاقات)، أنصاف أقطار أصغر للحقول والأزرار |
| الظلال | ظلال توهج متعددة الطبقات بـ `--glow` |
| الانتقال | `cubic-bezier(.16,1,.3,1)` (إحساس expo-out) |
| الحدود | شعرية 1px بـ `--border` |

## مبادئ التخطيط (كما ظهرت في الموقع المرجعي)

- قاعدة غرافيت داكنة مع مميزات زرقاء وألواح زجاجية خفيفة.
- RTL أولاً: العربية الاتجاه الافتراضي؛ `dir="rtl"` على `<html>`، الشريط الجانبي يميناً، النص محاذى يميناً.
- مسافات سخية، بطاقات مستديرة، رفعة عند التحويم مع توهج.
- الجوال: شريط تبويبات سفلي + درج همبرغر بدل الشريط الجانبي، مع حشوة سفلية للصفحة حتى لا يحجب الشريطُ المحتوى.

## التحقق

قورنت لقطات للموقع المرجعي (متصفح سحابي) بلقطات هذا التطبيق (Playwright) — نفس الألوان والخطوط وأنصاف الأقطار والتوهج وسلوك RTL. أي انحراء يُكتشف في فحص الجودة البصري يُصلَح ويُعاد فحصه (انظر QA_REPORT.md).
